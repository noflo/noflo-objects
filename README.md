# @noflo/objects

Object Utilities for [NoFlo](http://noflojs.org/)

This package provides utility components to manipulate objects in NoFlo.

An object in this context isn't an object in the sense of OOP, but in
the sense of a native JavaScript object, or basically a hash/dictionary.
These components let you manipulate them as IPs in NoFlo.

## Usage

Install the package:

    npm install @noflo/objects

The components are then available under the `objects/` namespace, for
example `objects/GetObjectKey`.
